# Домашний экран Swift 2

Своего лаунчера в ZerOS I нет: на телефоне стоит **штатный Trebuchet** прошивки —
`com.android.launcher3`, activity `.lineage.LineageLauncher`, APK в
`/system/product/priv-app/TrebuchetQuickStep/`.

Эксперименты с домашним экраном удалены из репозитория: HomeWatch (форк AOSP
Launcher3, Magisk-модуль `homewatch`) и ZerHome (свой лаунчер
`com.zeroc.home`). Их исходники и история остались в git — до коммита
`3b2f71e` включительно.

См. `../README.md` (состояние устройства) и `../../docs/versions.md` (версии).
