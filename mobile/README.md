# ZerOS Mobile

Мобильная оболочка поверх обычного Android: **Android не режем**, наша часть — ZerOS Shell
(обычный APK, выбирается как домашний экран) и свой пакетный формат `.zpk`.

Android остаётся целым: системные сервисы, SystemUI и штатный лаунчер работают как обычно.
Пользователь видит ZerOS Shell, но под ним — стандартный Android, и в любой момент можно
вернуться к штатному лаунчеру.

## Три столпа проекта

| # | Столп | Что делаем | Где код |
|---|-------|------------|---------|
| 1 | **ZerOS Shell** | домашний экран, меню приложений, список задач, хост `.zpk`; работает без root | `shell/` |
| 2 | **Пакетный менеджер .zpk** | свой формат пакетов, реестр, установка/подпись/обновление; рантаймы: Web (v0.1), Python, JVM | `pkgs/` |
| 3 | **Совместимость с Android** | любые APK ставятся и запускаются штатно; `.zpk` — параллельный формат, не замена | — |

Плюс: `apps/` — наши приложения (переносим часы Zepp, DOOM, калькулятор), `tools/` — утилиты,
`device/` — паспорта целевых устройств, `docs/` — спецификации.

## Целевые устройства

| Устройство | Чип | Android | RAM | Роль |
|-----------|-----|---------|-----|------|
| LG X210DS (K7) | MT6580 | 5.1 (API 22) | 1 ГБ | первый полигон, слабое железо |
| (далее) | MTK/Unisoc | 7–9 (API 24–28) | 2–4 ГБ | целевой минимум для ZerOS Mobile |

Правило: **сначала 1 ГБ RAM / API 22**, потом вверх. Если живо на слабом — на мощном полетит.

## Правила работы над проектом

1. **Всё обратимо.** Систему не трогаем; если всё же правится раздел/прошивка — сначала полный
   дамп (`docs/build-and-flash.md`).
2. **Ничего не удаляем из рабочих проектов.** Существующие папки Zepp/DOOM/simulator остаются на месте,
   см. `notes/registry.md`.
3. **Сборка только в ASCII-путях** (temp), исходники — в этом дереве.
4. **Минимум зависимостей.** Цель — 1 ГБ RAM: UI на обычных Android View, `.zpk` — во встроенном
   WebView, без тяжёлых фреймворков.
5. **Одна ответственность на процесс.** Shell, PackageManager и RuntimeHost разделяются логически,
   но в v0.1 живут внутри процесса Shell.
