# ZerOS

Исходники ZerOS: оболочка поверх обычного Android и прошивки для конкретных
устройств. Здесь только **наш** код и скрипты — сторонние ROM, TWRP, дампы и
бэкапы не хранятся.

## Структура

```
mobile/                     ZerOS Mobile — мобильная часть
├─ README.md                идея проекта, столпы, правила
├─ docs/
│  ├─ versions.md           поколения ZerOS и схема версий
│  ├─ android-versions.md   поддерживаемые версии Android по устройствам
│  ├─ architecture.md       слои, процессы, IPC
│  └─ palette.md            цвета и токены оформления
├─ marmite/                 Wileyfox Swift 2 (кодовое имя marmite)
│  ├─ README.md             паспорт устройства, состояние, прошивка
│  ├─ home/                 заметка: домашний экран — штатный Trebuchet
│  └─ firmware/             скрипты прошивки, заметки по руту, Magisk-модули
```

Каждое устройство — своя папка внутри `mobile/` (`marmite`, дальше по мере
появления). Общий код живёт уровнем выше, в `mobile/`.

## Версии

- Нумерация — по поколениям: **ZerOS I 0.1.0**, где поколение привязано к базе
  Android (10 → I, 11 → II, 12 → III, 13 → IV, дальше по порядку). Полные
  правила — в [`mobile/docs/versions.md`](mobile/docs/versions.md).
- Внутри поколения: правка — **+0.0.1**, новая функция — **+0.1.0**, ломающая
  переделка — **+1.0.0**. Первая версия поколения — `0.1.0`.
- Версия пишется в шапку приложения, в `versionName`, в README и в сообщение
  коммита; тег релиза — `I-0.1.0`, `IV-0.1.0`.
- Прошивки нумеруются по той же схеме; каждая версия — отдельный тег и архив
  в **Releases**.
- `ZerOS Home` 1.1 и версии `0.0.x` — история по старой схеме; первый релиз по
  новой — **ZerOS I 0.1.0** на Wileyfox Swift 2.

## Релизы

В **Releases** выкладывается полная прошивка устройства (zip для recovery),
исходники к ней — в этом репозитории. Тег совпадает с поколением и версией,
например `I-0.1.0`.

## Сборка

Прошивка и модули marmite собираются по инструкциям
`mobile/marmite/README.md` и `mobile/marmite/firmware/README.md`. Сборка только
в ASCII-пути (`%TEMP%`, `C:\work`): кириллица в пути ломает `aapt2`.

## Лицензия

Код ZerOS — наш; шрифты Inter и Redaction распространяются по SIL OFL.
