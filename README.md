# ZerOS

Исходники ZerOS: оболочка поверх обычного Android и прошивки для конкретных
устройств. Здесь только **наш** код и скрипты — сторонние ROM, TWRP, дампы и
бэкапы не хранятся.

## Структура

```
mobile/                     ZerOS Mobile — мобильная часть
├─ README.md                идея проекта, столпы, правила
├─ docs/
│  ├─ android-versions.md   поддерживаемые версии Android по устройствам
│  ├─ architecture.md       слои, процессы, IPC
│  └─ palette.md            цвета и токены оформления
├─ marmite/                 Wileyfox Swift 2 (кодовое имя marmite)
│  ├─ README.md             паспорт устройства, сборка, прошивка
│  ├─ home/                 HomeWatch — AOSP Launcher3 (android-10.0.0_r47)
│  └─ firmware/             скрипты прошивки и заметки по руту
```

Каждое устройство — своя папка внутри `mobile/` (`marmite`, дальше по мере
появления). Общий код живёт уровнем выше, в `mobile/`.

## Версии

- Каждая программа начинается с **0.0.1**, каждое изменение — **+0.0.1**
  (0.0.1 → 0.0.2 → 0.0.3). Версия пишется в шапку приложения, в `versionName`
  и в README.
- Прошивки нумеруются по той же схеме; каждая версия — отдельная папка/тег и
  архив в **Releases**.
- `ZerOS Home` 1.1 — последний релиз по старой схеме; с `0.0.1` нумерация новая.

## Релизы

В **Releases** выкладывается полная прошивка устройства (zip для recovery),
исходники к ней — в этом репозитории. Тег совпадает с версией, например
`0.0.1`.

## Сборка

HomeWatch (AOSP Launcher3) собирается без Gradle: `android.jar` + `d8` + `aapt2` +
`apksigner`. Подробности и грабли — в `mobile/marmite/home/README.md`. Сборка только в
ASCII-пути (`%TEMP%`, `C:\work`), кириллица в пути ломает `aapt2`.

## Лицензия

Код ZerOS — наш; шрифты Inter и Redaction распространяются по SIL OFL.
